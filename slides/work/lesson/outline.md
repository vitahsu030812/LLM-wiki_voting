## 0. 前提

| 項目 | 內容 |
|------|------|
| 對象 | 員林市民（含首投族），不需要政治背景 |
| 目標 | 18 分鐘學會：看懂選票 → 看懂職位 → 看懂計票 → 讀政見 → 查承諾 → 去投票 |
| 教材 | `wiki/lessons/` 6 課；員林實例只用資料層已有的數字 |
| 風格 | 沿用選民參考簡報：雜誌排版、圖 60／文 40、色票 #BEDEFF #FFF2A7 #FFA500 #930031 |
| 中立 | 例子以制度與數字為主角；不出現「投誰」題目；不轉載個別候選人兌現度分數 |
| 互動 | 每課結尾一題小測驗，答案收合在「看答案」（不需 JavaScript，列印時展開） |
