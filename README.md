# 2026 員林選前小教學 — 彰化縣員林市選舉知識庫

一個由 LLM Agent 維護的**學習型 LLM Wiki**。用途是 2026-11-28 地方選舉前的公民小教學，讓員林市民（含首投族）在投票前學會五件事：

> 看懂選票 → 看懂職位 → 看懂計票 → 讀政見 → 查承諾 → 去投票

維護規則都寫在 [AGENTS.md](AGENTS.md)。任何 Agent 開始工作前都要先讀它。

## 怎麼使用

**想學**：從 [課程地圖](wiki/lessons/00-課程地圖.md) 開始，或直接打開 `slides/2026員林市選舉-選前小教學.html`。這份簡報不需要網路，小測驗按「看答案」就會展開。

**想查資料**：從 [wiki/index.md](wiki/index.md) 找頁面。建議用 [Obsidian](https://obsidian.md/) 把整個資料夾開成 Vault，WikiLink 和 Graph View 才會正常顯示。

**想請 Agent 維護**：直接跟它說要做哪一種工作，它會依 AGENTS.md 第五章的流程處理：

| 工作 | 範例指令 | 流程 |
|------|----------|------|
| Ingest | 「請 ingest raw/official/XXX.pdf」 | 讀原始資料 → 更新 wiki → 更新 index、log |
| Query | 「三和里有哪些候選人？」 | 先讀 index，再讀相關頁面回答 |
| Lint | 「做一次健康檢查」 | 找孤立頁、矛盾、過時資訊、缺漏連結 |
| Teach | 「新增第 7 課」「重做教學簡報」 | 先讀課程地圖 → 寫課程頁 → 走簡報流程 |

每次改動都會追加一筆紀錄到 [wiki/log.md](wiki/log.md)。

## 簡報怎麼做出來的

簡報不是直接手寫，而是走一條**有檢查關卡的流程**。每一步產出一個檔案，接著過一道關卡，沒通過就退回造成問題的那一步：

```
G 知識圖譜 → 0 素材盤點 →〈A〉→ 1 大綱 →〈B〉→ 2 逐頁規格 →〈C〉→ 3 製作 →〈D〉→ 4 收尾
```

| 關卡 | 檢查什麼 |
|------|----------|
| A 事實卡 | 每個數字的原文片段真的出現在 wiki 頁；計算卡重新算一次 |
| B 大綱 | 一頁一個主張、圖型合法；教學版每課都要有目標頁和測驗頁 |
| C 規格 | 圖表數字對得到事實卡、沒有評價用語；題目逐字出現在課程頁 |
| D 成品 | 畫面上的數字都來自規格、只用指定色票；桌機與手機版面都不溢出 |

完整說明見 [slides/work/PIPELINE.md](slides/work/PIPELINE.md)。

### 指令（在 Git Bash 執行，需要 Perl）

```bash
cd slides/work
```

```bash
DECK=lesson perl check.pl all
```

```bash
DECK=lesson perl build_slides.pl
```

- `DECK=lesson` 會讀寫 `slides/work/lesson/`，產出選前小教學。
- 省略 `DECK`（預設 `voter`）則產出選民參考簡報。
- `check.pl` 結束碼為 0 表示通過，1 表示有 ERROR。WARN 不擋流程。
- 版面溢出檢查要在瀏覽器裡用 `check_layout.js` 跑。
- 封存的版本放在 `slides/work/archive/`。

## 基本原則

1. **只寫查得到的事**：每個數字都要能追溯到 wiki 頁，wiki 再追溯到官方公告或媒體報導。傳言不收。
2. **中立**：只描述事實，不評價候選人。同一場選舉的候選人全部列出，依號次排列。
3. **教制度，不教投誰**：小測驗只考規則與查證方法；政見兌現度只教評分方法，不轉載個別分數。
4. **法規附條號**：法規說法要附條號與修正日期，尚未施行的條文不當作本次規則。
5. **原始資料不改**：`raw/` 只讀；所有整理都寫在 `wiki/`。
